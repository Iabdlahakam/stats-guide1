# Company Launch Plan

## First 7 Days

- Choose company name and check domain availability.
- Create a professional email address.
- Draft mission, vision, and service descriptions.
- Create a simple landing page with intake form and call-to-action.
- Prepare the first three service packages.
- Build branded templates for proposals and deliverables.

## Days 8–30

- Launch social profiles on LinkedIn, YouTube, X/Twitter, Instagram, and Facebook if relevant.
- Publish 10 short educational posts about research planning for residents.
- Record 3 short YouTube videos answering common trainee research questions.
- Contact 20–30 potential users for discovery calls.
- Offer beta packages to the first 5–10 clients.
- Track time spent, deliverables requested, revision patterns, and willingness to pay.

## Days 31–60

- Improve templates based on real client work.
- Build the internal prompt library for repeatable deliverables.
- Create before/after examples using fictional research projects.
- Add testimonials when available and permitted.
- Standardize pricing and turnaround times.
- Begin building a private AI dashboard only if the manual workflow is repeating.

## Days 61–90

- Complete 20 paid or pilot projects.
- Identify the top 3 most requested deliverables.
- Convert those deliverables into semi-automated workflows.
- Decide whether to hire a developer, technical cofounder, or fractional CTO.
- Prepare specifications for a private AI assistant or client portal.

## Key Metrics

- Number of intake forms submitted
- Number of paid clients
- Conversion rate from inquiry to payment
- Average delivery time per package
- Revision rate
- Client satisfaction score
- Repeat/referral rate
- Most common project type
- Most common missing information
