# Step-by-Step Company Launch Plan

## Phase 1: Lock the Foundation

**Goal:** Make the brand consistent before publishing widely.

1. Use **Clinical Research Compass** as the public name.
2. Use the locked mission statement everywhere.
3. Use the tagline: “Expert guidance for rigorous and impactful clinical research.”
4. Use the flat CRC compass logo as the master logo.
5. Use navy and teal consistently across website, posts, and worksheets.
6. Add the standard disclaimer to tools and service pages.

## Phase 2: Publish the First Lead Magnet

**Goal:** Turn the PICOT content into an audience-building asset.

1. Finalize the branded PICOT worksheet PDF.
2. Create the matching PICOT infographic or mind-map image.
3. Write the full explanatory caption using the approved educational post model.
4. Publish on LinkedIn and Instagram.
5. Use the CTA: **“Comment COMPASS for the worksheet.”**
6. Send the worksheet manually at first and track every request.
7. Save common questions as future post ideas.

## Phase 3: Build the Research Question Starter Pack

**Goal:** Expand from one worksheet into a complete branded educational product.

1. Create a branded cover page.
2. Add the PICOT worksheet.
3. Add the PEO worksheet.
4. Add the SPIDER worksheet.
5. Add framework-selection guidance.
6. Add validation checklists.
7. Add a light repeating watermark and branded footer.
8. Export as a single PDF.
9. Create one matching infographic post for each framework.

## Phase 4: Set Up Accounts and Simple Business Infrastructure

**Goal:** Make it easy for people to find, trust, and contact the company.

1. Buy or reserve the domain.
2. Create a professional email address.
3. Create LinkedIn company page.
4. Refresh the founder LinkedIn profile.
5. Create YouTube channel.
6. Create Instagram and other priority social accounts.
7. Set up an email list or simple contact form.
8. Set up Calendly or another booking link.
9. Set up Stripe or another payment option before offering paid services.

## Phase 5: Start the Consultancy Offer

**Goal:** Convert attention into real research-support work.

Start with a small offer before promising full A–Z support.

**Recommended first offer:** Research Question Review / Research Idea Clinic.

**Deliverables:**

- Refined research question.
- Recommended framework: PICOT, PEO, SPIDER, or another appropriate structure.
- Study design direction.
- Feasibility concerns.
- Missing information checklist.
- Next-step action plan.

## Phase 6: Build the Private AI Assistant

**Goal:** Make your delivery faster and more consistent while keeping expert review in control.

1. Build an intake prompt.
2. Build a research question refinement prompt.
3. Build a framework-selection prompt.
4. Build a protocol-outline prompt.
5. Build a data collection planning prompt.
6. Build a statistical analysis planning prompt.
7. Build a quality-review prompt that checks consistency.
8. Store every approved output as a reusable template.

## 30-Day Execution Checklist

- [ ] Website updated with Clinical Research Compass branding.
- [ ] Logo used on website and worksheet drafts.
- [ ] PICOT post published.
- [ ] PICOT worksheet delivered to at least 10 interested people.
- [ ] PEO worksheet drafted.
- [ ] SPIDER worksheet drafted.
- [ ] Research Question Starter Pack assembled.
- [ ] LinkedIn company page created.
- [ ] YouTube channel created.
- [ ] Intake form created.
- [ ] First paid or pilot Research Idea Clinic offered.

## Metrics to Track

- Worksheet requests.
- Email signups.
- Comments containing “COMPASS.”
- Direct messages asking for help.
- Intake forms submitted.
- Paid consultations booked.
- Most common research question problems.
- Most requested deliverables.
