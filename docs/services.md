# Consulting Services and Packages

## Service Strategy

Start with a small number of clear packages. Avoid offering unlimited custom work before the workflow is stable. The first offers should connect directly to the educational content system and the Research Question Starter Pack.

## Package 1: Research Question Review

**Best for:** Clients with a broad clinical idea who need a rigorous, answerable research question.

**Deliverables:**

- Refined research question.
- Recommended framework: PICOT, PEO, SPIDER, or another appropriate structure.
- Completed framework worksheet.
- Common mistake review.
- Feasibility notes.
- Next-step action plan.

**Suggested beta price:** $49–$149.

## Package 2: Research Idea Clinic

**Best for:** Clients who need direction before writing a protocol.

**Deliverables:**

- Refined research question.
- Study design recommendation.
- Feasibility screen.
- Required data elements.
- Missing-information checklist.
- 30-day next-step action plan.

**Suggested beta price:** $149–$399.

## Package 3: Protocol Starter Package

**Best for:** Clients who need a protocol outline or first draft.

**Deliverables:**

- Protocol title and background outline.
- Objectives and hypotheses.
- Inclusion and exclusion criteria.
- Outcome definitions.
- Study procedures.
- Ethics and IRB preparation checklist.
- Basic statistical analysis plan outline.

**Suggested beta price:** $299–$799.

## Package 4: Data Collection Package

**Best for:** Clients preparing chart review, survey, registry, or prospective data collection.

**Deliverables:**

- Case report form structure.
- Variable list.
- Data dictionary.
- Coding guide.
- Missing-data rules.
- Data quality checks.
- Excel/CSV-ready structure.

**Suggested beta price:** $299–$999.

## Package 5: Statistical Analysis Plan Package

**Best for:** Clients who need a clear analysis plan before analysis begins.

**Deliverables:**

- Primary and secondary analysis plan.
- Descriptive statistics plan.
- Group-comparison strategy.
- Regression or survival-analysis outline when relevant.
- Missing-data plan.
- Table and figure shells.
- Plain-language explanation of planned analyses.

**Suggested beta price:** $399–$1,200.

## Package 6: Protocol-to-Publication Mentorship

**Best for:** Clients who want A–Z support.

**Deliverables may include:**

- Idea refinement.
- Protocol development.
- IRB preparation support.
- Data collection tools.
- Analysis planning.
- Abstract, poster, or manuscript roadmap.
- Scheduled review calls.
- Project accountability tracking.

**Suggested beta price:** $1,500–$5,000+ per project.

## Recommended First Paid Offer

Begin with **Research Question Review** because it is directly connected to the first educational content package and is easier to deliver consistently. Use the PICOT, PEO, and SPIDER worksheets as the bridge from free education to paid guidance.
