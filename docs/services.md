# Consulting Services and Packages

## Service Ladder

Start with a small number of clear packages. Avoid offering unlimited custom work before the workflow is stable.

## Package 1: Research Idea Clinic

**Best for:** Clients with a vague idea who need direction.

**Deliverables:**

- Refined research question
- PICOT framework
- Feasibility screen
- Study design recommendation
- Missing-information checklist
- Next-step action plan

**Suggested beta price:** $49–$149.

## Package 2: Protocol Starter Package

**Best for:** Clients who need a protocol outline or first draft.

**Deliverables:**

- Protocol title and background outline
- Objectives and hypotheses
- Study design and setting
- Inclusion/exclusion criteria
- Outcome definitions
- Data source and collection approach
- Ethics/IRB preparation checklist
- Basic statistical analysis plan outline

**Suggested beta price:** $299–$799.

## Package 3: Data Collection Package

**Best for:** Clients preparing chart review, survey, registry, or prospective data collection.

**Deliverables:**

- Case report form structure
- Variable list
- Data dictionary
- Coding guide
- Missing-data rules
- Data quality checks
- Excel/CSV-ready structure

**Suggested beta price:** $299–$999.

## Package 4: Statistical Analysis Plan Package

**Best for:** Clients who need a clear plan before analysis.

**Deliverables:**

- Primary and secondary analysis plan
- Descriptive statistics plan
- Group-comparison strategy
- Regression or survival-analysis outline when relevant
- Missing-data plan
- Table and figure shells
- Plain-language explanation of planned analyses

**Suggested beta price:** $399–$1,200.

## Package 5: Protocol-to-Publication Mentorship

**Best for:** Clients who want A–Z support.

**Deliverables may include:**

- Idea refinement
- Protocol development
- IRB preparation support
- Data collection tools
- Analysis planning
- Abstract/poster/manuscript roadmap
- Scheduled review calls
- Project accountability tracking

**Suggested beta price:** $1,500–$5,000+ per project.
